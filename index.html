คำสั่งที่ใช้บ่อย

กดคัดลอก แล้ววางใน Command Prompt (เปิดแบบ Run as administrator เมื่อจำเป็น)

คีย์ลัดที่ควรรู้

ช่วยได้มากตอนเครื่องค้างหรือหาเมนูไม่เจอ

  • CtrlShiftEscเปิด Task Manager
  • WinRเปิดหน้าต่าง Run
  • WinXเมนูเครื่องมือระบบ
  • WinIเปิดการตั้งค่า
  • WinPเปิดเมนู Project เลือกรูปแบบการแสดงผลเมื่อต่อหน้าจอที่สอง
  • WinCtrlShiftBรีเซ็ตไดรเวอร์จอ เมื่อภาพค้างหรือจอดับ
  • CtrlAltDelหน้าจอจัดการเซสชัน

อัปเดตล่าสุด

สิ่งใหม่และการปรับปรุงล่าสุดของเว็บไซต์

    คำถามที่พบบ่อย

    ข้อควรรู้ก่อนลงมือแก้ปัญหา

    ควรสำรองข้อมูลก่อนลองแก้ไหม?

    ควรทุกครั้ง โดยเฉพาะก่อนฟอร์แมต ติดตั้ง Windows ใหม่ หรือแก้ค่าใน BIOS ให้คัดลอกไฟล์สำคัญไปไว้ที่ไดรฟ์ภายนอกหรือคลาวด์ก่อน

    ฟอร์แมตเครื่องแล้วจะแก้ได้ทุกปัญหาไหม?

    ไม่เสมอไป การติดตั้ง Windows ใหม่แก้ได้เฉพาะปัญหาที่เกิดจากซอฟต์แวร์ ถ้าต้นเหตุคือฮาร์ดแวร์ เช่น ฮาร์ดดิสก์เสียหรือ RAM มีปัญหา อาการจะกลับมาอีก

    เมื่อไหร่ควรให้ช่างตรวจ?

    เมื่อลองวิธีพื้นฐานแล้วเครื่องยังเปิดไม่ติด มีกลิ่นไหม้หรือความร้อนสูงผิดปกติ ได้ยินเสียงคลิกจากฮาร์ดดิสก์ หรือมีข้อมูลสำคัญที่ไม่มีสำรอง

    เครื่องช้าลงหลังอัปเดต Windows ต้องทำอย่างไร?

    รีสตาร์ทเครื่องและเปิดทิ้งไว้สักพัก เพราะระบบอาจยังจัดทำดัชนีไฟล์อยู่ จากนั้นตรวจพื้นที่ว่างในไดรฟ์ C: และอัปเดตไดรเวอร์การ์ดจอ

    ใช้โปรแกรมกำจัดไวรัสหลายตัวพร้อมกันได้ไหม?

    ไม่ควร เพราะโปรแกรมอาจขัดกันและทำให้เครื่องช้า Windows Security ที่มากับเครื่องเพียงพอสำหรับการใช้งานทั่วไป

    ยังหาวิธีแก้ไม่เจอ?

    ลองค้นหาด้วยรหัส error หรือกลับไปเริ่มตัวช่วยหาวิธีแก้อีกครั้ง
